Интеллектуальный Telegram-бот для абитуриентов МГТУ "СТАНКИН", построенный на базе архитектуры **Advanced RAG (Retrieval-Augmented Generation)**. 

Бот консультирует поступающих по вопросам проходных баллов, стоимости обучения, наличия бюджетных мест, а также предоставляет развернутую информацию о направлениях подготовки на основе извлеченных текстовых данных (парсинг таблиц и транскрибации подкастов).

---

## 📌 Особенности проекта

В отличие от классического RAG, который часто путает числовые данные и смысловой текст, в данном проекте реализован сложный пайплайн обработки запросов:

1. **Многоуровневый поиск (Hybrid-like Routing):** Система разделяет фактологические запросы (цифры, баллы, цены) и семантические запросы (описание направлений, отзывы) с помощью `SelfQueryRetriever`.
2. **Двухэтапная фильтрация (Retrieve & Rerank):** Первичный поиск извлекает топ-N кандидатов (Embeddings), после чего Cross-Encoder модель переранжирует их для достижения максимальной релевантности.
3. **Защита от галлюцинаций (Sanitizer):** Кастомная обертка `SafeRetriever` отфильтровывает битые или пустые документы до их попадания в пайплайн генерации.
4. **Модульная ETL-архитектура:** Процессы извлечения, трансформации и загрузки данных (Extract, Transform, Load) строго отделены от логики бота и генерации ответов.

## 🛠 Технологический стек

* **Интерфейс:** `aiogram 3.x` (Асинхронный Telegram-бот).
* **LLM Orchestration:** `LangChain`.
* **Векторная СУБД:** `ChromaDB`.
* **Embeddings:** `intfloat/multilingual-e5-large` (HuggingFace) — оптимизировано для многоязычного и русского семантического поиска.
* **Reranker:** `BAAI/bge-reranker-v2-m3` (Cross-Encoder) — для точного ранжирования найденных фрагментов.
* **LLM (Генерация и фильтрация):** `Gemini 2.5 Flash` & `Gemini 2.0 Flash` через OpenRouter API.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_USERNAME/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git
cd НАЗВАНИЕ_РЕПОЗИТОРИЯ
```

### 2. Настройка виртуального окружения
```bash
python -m venv venv
# Активация для Windows:
venv\Scripts\activate
# Активация для Linux/Mac:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте файл `.env` в корневой папке проекта и добавьте ваши API ключи:
```env
OPENROUTER_API_KEY=ваш_ключ_от_openrouter
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
```

## 🗄 Управление базой знаний (ETL)

Перед первым запуском бота необходимо наполнить векторную базу данных знаниями. Благодаря модульной архитектуре, вы можете обновлять разные типы данных независимо друг от друга.

1. **Добавление табличных данных (баллы, цены, места):**
   ```bash
   python ingest_tables.py
   ```
2. **Добавление текстовых данных (подкасты, описания):**
   ```bash
   python ingest_podcasts.py
   ```
3. *(Опционально)* **Сброс базы данных:**
   Если структура данных изменилась, вы можете полностью очистить `ChromaDB`:
   ```bash
   python -c "from chroma_db_operations.db_manager import reset_database; reset_database()"
   ```
4. *(Опционально)* **Проверка качества поиска:**
   Запустите тестовые запросы напрямую в базу, чтобы увидеть работу реранкера и значения метрики дистанции (L2):
   ```bash
   python debug_db.py
   ```

## 🧠 Под капотом: Как работает пайплайн запроса

Когда пользователь отправляет сообщение боту (например: *"Какой проходной балл на информатику?"*), система выполняет следующие шаги:

1. **Query Construction (Self-Querying):** LLM-фильтр анализирует вопрос пользователя и извлекает метаданные. Если в запросе речь идет о цифрах (балл, стоимость), LLM динамически создает фильтр `eq('source_type', 'Таблица')`, отсекая "шумные" текстовые документы.
2. **Dense Retrieval:** `ChromaDB` с помощью модели `multilingual-e5-large` находит топ-30 (параметр `k=30`) наиболее близких по смыслу векторов.
3. **Sanitization:** `SafeRetriever` проверяет извлеченные документы на целостность (удаляет пустые строки), чтобы не сломать следующие этапы.
4. **Contextual Compression (Reranking):** Модель `BAAI/bge-reranker-v2-m3` заново оценивает связь между изначальным вопросом и 30 найденными документами, оставляя только **Топ-5** самых точных.
5. **Generation:** В `Gemini 2.5 Flash Lite` отправляется строгий системный промпт (с запретом на галлюцинации и выдумку цифр) вместе с отфильтрованным контекстом.
6. **Delivery:** Бот возвращает пользователю аккуратно отформатированный HTML-ответ с указанием ссылок на первоисточники (метаданные документов).
